nesp32

A small Wi-Fi computer that plugs into controller port 2 of a Nintendo Entertainment System and gives the console what it never had: the Internet, files, and another console to play against.

Install the firmware Source on GitHub

What it is

A nesp32 is an M5Stack StickS3 with a level-shifting hat and this firmware. The console needs no modification, and the games and programs that use it are ordinary ROMs. One firmware serves every program: a ROM says what it needs when it starts, and the nesp32 provides it.

To come: a photograph of a nesp32 in a console.

What it does

NESpedia

A Wikipedia reader: type a search on the console and read the article.

NES Jukebox

Plays rips of NES games' music, and recordings, through the console's own sound chip.

Two consoles

Two-player games over a network, each player on a console of their own.

Setup

Wi-Fi joined from the controller, a link test, and the nesp32's files as a USB drive. Nothing is set up from a computer.

Getting started

  1. Get the parts. An M5Stack StickS3 and the hat. To come: where the hat is had, or how it is made.
  2. Install the firmware from the firmware page, in Chrome, Edge or Opera on a computer.
  3. Get the cartridge. One ROM with a menu and all the programs, for a flash cartridge or the MiSTer. To come: where the ROM is downloaded.
  4. Plug it in. The nesp32 goes in controller port 2. Start the cartridge and join a network from Setup.

Status

Work in progress. Every program has run on a StickS3, on a real NES and on the MiSTer's NES core. To come: what is tested and what is not, kept in step with the README.
