NESP32

An inexpensive, DIY wireless network interface for the Nintendo Entertainment System (NES) based on the ESP32 S3 microcontroller.

Install the firmware Download the ROM Project on GitHub

About

The NESP32 provides Internet access, media streaming, and online gaming capabilities to NES software.

The NESP32 is built using the M5 StickS3. The StickS3 is an all-in-one IoT development kit includes a dual core processor, flash storage, audio, WiFi, color LCD screen, battery, USB interface, and buttons. A custom hat plugs into the top of the device and connects to controller port 2 of the NES.

Extensible firmware provides an API that any cartridge-based software can interface with. A setup program allows the wifi and USB storage to be configured from the NES itself.

The NESP32 is an evolution of NES Radar where the controller port interface was originally conceived.

What it does

NESpedia

A Wikipedia reader: type a search on the console and read the article.

NES Jukebox

Plays rips of NES games' music, and recordings, through the console's own sound chip.

Two consoles

Two-player games over a network, each player on a console of their own.

Setup

Wi-Fi joined from the controller, a link test, and the nesp32's files as a USB drive. Nothing is set up from a computer.

Getting started

  1. Get the parts. An M5 StickS3 and the NESP32 hat to go with it.
  2. Install the software from the firmware page right from your browser.
  3. Get the cartridge ROM. Use it with a flash cart or MiSTer FPGA w/SNAC adapter.
  4. Plug it in. Attach the hat and connect the NESP32 to controller port 2.
  5. Boot it up! Power up the NESP32 and the NES, then run the Setup utility to join a WiFi network.
