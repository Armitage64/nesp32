NESP32

An inexpensive, DIY wireless network interface for the Nintendo Entertainment System (NES) based on the ESP32 S3 microcontroller.

Install the firmware Download the cartridge Project on GitHub

About

  • Provides Internet access, media streaming, and online gaming capabilities to NES software.
  • Built using the M5 StickS3. The StickS3 is a ~$20 all-in-one IoT development kit that includes a dual core processor, flash storage, audio, WiFi, color LCD screen, battery, USB interface, and buttons.
  • A custom hat plugs into the top of the device and connects to controller port 2 of the NES.
  • Extensible firmware provides an API that any cartridge-based software can interface with. A setup program allows the wifi and USB storage to be configured from the NES itself.
  • The NESP32 is an evolution of NES Radar where the controller port serial interface was originally conceived.

Applications

NESpedia

A Wikipedia reader: search and read articles directly on the console.

NES Jukebox

Play NES music in VGM/VGZ format and PCM audio at up to 20kHz through the console's own sound chip.

The original NES game converted for 2-player online over a LAN or WAN!

Another classic NES game updated with 2-player online over a LAN or WAN!

Getting started

  1. Get the parts. An M5 StickS3 and the NESP32 hat to go with it.
  2. Install the software from the firmware page right from your browser.
  3. Get the cartridge ROM. Use it with a flash cart or MiSTer FPGA w/SNAC adapter.
  4. Plug it in. Attach the hat and connect the NESP32 to controller port 2.
  5. Boot it up! Power up the NESP32 and the NES, then run the Setup utility to join a WiFi network.
