An inexpensive, DIY wireless network interface for the Nintendo Entertainment System (NES) based on the ESP32 microcontroller.

Install the firmware Download the cartridge Project on GitHub

About

  • Provides Internet access, media streaming, and online gaming capabilities to NES software.
  • Built using the M5 StickS3, a ~$20 all-in-one IoT development kit that includes a dual core processor, flash storage, audio, Wi-Fi, color LCD screen, battery, USB interface, and buttons1.
  • A custom hat plugs into the GPIO header at the bottom of the device and connects to controller port 2 of the NES.
  • Extensible firmware provides an API that any cartridge-based software can interface with. A setup program allows the Wi-Fi and USB storage to be configured from the NES itself.
  • Bluetooth (BLE) keyboard support for programs with text entry.
  • The NESP32 grew out of NES Radar and connectedNES, projects that first explored the use of the NES controller port as a data link.
  • NTSC-only for now. PAL support is planned.
1 The M5 StickC-Plus2 is also fully supported or you can use a generic ESP32 without a screen.

Applications

NESpedia

A Wikipedia reader: search and read articles directly on the console.

Jukebox

Play NES music in VGM/VGZ format and PCM audio at up to 20kHz through the console's own sound chip.

NES Radar

Live air traffic around any airport, on a radar scope drawn by the console.

NESradio

Live radio from NPR, KEXP, BBC World Service and more on a radio dial, with the song that's playing.

Weather

Current conditions and a 5-day forecast for your US zip code, with pictures.

Online Gaming

Play Dr. Mario, Tetris, Contra, and TMNT2 online using room codes, no firewall changes required!

Bluesky

Read the latest posts from your favorite Bluesky accounts, after ConnectedNES.

Setup

Configure Wi-Fi/USB and test connectivity directly from the console.

Throughput Test

Benchmark the maximum speed the interface can support over the controller port.

Getting started

  1. Get the parts. An M5 StickS3 and the NESP32 hat to go with it.
  2. Install the software from the firmware page right from your browser.
  3. Get the cartridge ROM. Use it with a flash cart or MiSTer FPGA w/SNAC adapter.
  4. Plug it in. Attach the hat to the S3's bottom GPIO header, furthest from the LCD screen, and connect the NESP32 to controller port 2.
  5. Boot it up! Power up the NESP32 and the NES, then run the Setup utility to join a Wi-Fi network.

New to the NESP32? The user guide covers each of these steps and every program, and the build guide walks through building the hat and checking it before it's plugged in.
