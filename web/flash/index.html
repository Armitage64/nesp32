NESP32

Install NESP32 firmware on an M5Stack StickS3 or StickC Plus2 from your browser.

Connect your Stick to this computer with a USB data cable and press Connect. The right firmware for your Stick is chosen for you.

This browser cannot reach a USB serial port. Use Chrome, Edge or Opera on a computer. This page has to be served over HTTPS, or from localhost, to reach a USB serial port.

Note

  • Installing firmware replaces what is current on the Stick, including UIFlow
  • If this is the first time installing on a StickS3, put the device in boot mode. Push and hold the power button on the side until the green light flashes. A StickC Plus2 needs no button.
  • On Windows, a StickC Plus2 may need the driver for its USB serial chip (CH9102) before the browser can see it.
  • The browser asks whether to erase first. Answer no when updating an existing NESP32 install to retain WiFi and stored files.

After Installation

  1. Fit the hat and plug the NESP32 into controller port 2.
  2. Ensure the Stick is powered on.
  3. Boot the NESP32 cartridge ROM and run the Setup utility to join a WiFi network.
