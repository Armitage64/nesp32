Install NESP32 firmware from your browser. Devices supported:

  • M5Stick S3
  • M5StickC Plus2
  • Generic ESP32‑S3 development board with at least 8MB flash and 8MB PSRAM
1. How is your device wired to the NES?

2. Connect your device to this computer with a USB data cable and press Connect.

This browser cannot reach a USB serial port. Use Chrome, Edge or Opera on a computer. This page has to be served over HTTPS, or from localhost, to reach a USB serial port.

Note

  • Installing firmware replaces what is currently on the Stick, including UIFlow.
  • If this is the first time installing on a StickS3, put the device in boot mode. Push and hold the power button on the side until the green light flashes. A StickC Plus2 needs no button.
  • On Windows, a StickC Plus2 may need the driver for its USB serial chip (CH9102) before the browser can see it.
  • Installing firmware replaces what is currently on the board.
  • ESP32‑S3 only. A StickC Plus2 or another ESP32 board is refused.
  • If the board doesn't appear when you press Connect, hold its BOOT button, press and release RESET, then release BOOT, and try again.
  • The browser asks whether to erase first. Answer no when updating an existing NESP32 install to retain Wi-Fi and stored files.

After Installation

  1. Fit the hat and plug the NESP32 into controller port 2.
  2. Ensure the Stick is powered on.
  3. Boot the NESP32 cartridge ROM and run the Setup utility to join a Wi-Fi network.
  1. Connect your adapter to controller port 2.
  2. Ensure the board is powered over USB.
  3. Boot the NESP32 cartridge ROM and run the Setup utility to join a Wi-Fi network.
